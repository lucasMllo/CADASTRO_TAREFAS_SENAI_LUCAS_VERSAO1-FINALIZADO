    Requisitos Funcionais

    RF01 — Histórico de atividades

    O sistema registra o horário em que cada tarefa foi adicionada, concluída ou excluída.

    Quando uma tarefa é concluída, o sistema também informa o tempo que levou desde sua criação até a conclusão.
    RF02 — Meta diária

    O sistema permite definir uma quantidade de tarefas para serem concluídas durante o dia.

    O progresso é atualizado automaticamente conforme as tarefas são concluídas.
